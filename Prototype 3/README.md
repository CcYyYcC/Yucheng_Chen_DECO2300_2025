# Prototype 3 – XR Prototype 3

This folder contains the final Unity prototype and all related documentation for Interactive Prototype 3.

## Overview
Prototype 3 extends the previous immersive drawing system by adding new **environmental and spatial interactions**, including:
- A **two-layer cabinet** with a pullable drawer and a hinged shutter door.  
- A **lever** for scene switching (pull down/up to change between Scene 0 and Scene 1).  
- A **camera height adjustment** system controlled by holding the right thumbstick and moving vertically.

These additions aim to test realism, usability, and immersion in an XR creative environment.

## Folder Structure
- **Prototype3_Final/** – Unity project files and scenes.  
- **TestFiles/** – Testing plan, questionnaire, and collected results.  
- **Build/** – APK build for Meta Quest headset.  
- **ExternalResources/** – Assets and references used during development.  
- **References_and_AI_Prompts/** – Documentation of AI-assisted workflows and citations.

## How to Use
1. Open the project in **Unity 2022.3.x (Built-in Pipeline)**.  
2. Load the main scene under `/Assets/Scenes/`.  
3. Build and deploy to a Meta Quest headset.  
4. Follow the testing plan in `/TestFiles/Testing_Plan_Prototype3.pdf`.
