# Procreate XR Prototype – Phase 2  

## Project Structure  

This repository contains the files and documentation for **Prototype 2** of the Procreate XR project.  

### 📂 Prototype2_Final  
- Unity project files for **Prototype 2**.  
- This folder includes the final version of the XR prototype implementation in Unity.  

### 📂 testfile  
- Contains all testing-related documents for Prototype 2:  
  - **Testing Plan** – describes objectives, tasks, methodology, and setup.  
  - **Testing Results** – raw data tables, participant feedback, and summary analysis.  
  - **Reflection** – analysis of findings, AI usage acknowledgement, and lessons learned.  

### 📂 software  
- Contains the **APK build** of Prototype 2.  
- This file can be directly installed and run on a VR headset (Meta Quest).  

### 📂 externalsourse  
- Contains external resources that were tested or considered during the development process.  
- These resources were **explored during prototyping** but not all of them were integrated into the final version of the prototype.  

### 📂 References and AI Prompts  
- Provides a record of **AI tool usage** and reflections on their role in development.  
- Includes **citations for external resources** used in the prototype.  
- Demonstrates transparency in how generative AI was applied during design and debugging.  

---

## Notes  
- This phase focuses on implementing XR interactions such as drawing, erasing, pressing physical buttons, opening a wrist menu, and remote grabbing tools.  
- The provided APK build enables testing on-device, while test files document the evaluation process and iteration insights.
